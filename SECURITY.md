# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately from the repository's
**Security** tab → **Report a vulnerability** (GitHub private vulnerability
reporting). Include what is affected, how to reproduce it and the version.

This applies too if you find a pull request, dependency or release that looks
malicious.

## Supported versions

Only the latest release gets fixes; the app offers updates from
Settings → App.
